# InfoLab: информатика оқыту платформасы (7–11 сыныптар)

Теория, практикалық тапсырмалар, автоматты тексеру, күнделікті баға, XP ұпай және сынып рейтингі. Интерфейс толығымен қазақ тілінде.

## Не бар

**Оқушыға:**
- мұғалім ашқан сабақтар: теория және тапсырмалар;
- 6 түрлі тапсырма: тест (бір жауап), тест (бірнеше жауап), қысқа жауап, **Python код** (сайттың ішінде жазып, іске қосып, тесттермен тексереді), ашық жауап, **практикалық жұмыс** (Excel/Word т.б. файлын жүктейді, мұғалім бағалайды);
- әр сабаққа 10 балдық баға, тоқсандық баға (85% → 5, 65% → 4, 40% → 3);
- XP ұпай, деңгейлер, 🔥 «қатарынан күндер», бүгінгі/апталық/жалпы рейтинг;
- оқулықтар (PDF).

**Мұғалімге:**
- сынып құру: оқушылар **сынып кодымен** тіркеледі;
- КТЖ бойынша 7–11 сыныптардың барлық тақырыбы дайын (2024–2025 жоспардан алынған);
- сабақты сыныпқа «Ашу» / «Жабу»; әр сабаққа **мерзім (дедлайн)** және кеш тапсыру ережесі: кештен кейін 100% / 75% / 50% ұпай немесе тапсыру жабылады;
- **журнал**: оқушы × сабақ кестесі, тоқсандық баға, Excel-ге (CSV) экспорт;
- ашық жауаптар мен практикалық жұмыстарды **рубрика** бойынша тексеру: әр критерийге балл қойылады, қосындысы мен кештен кейінгі ұпай автоматты есептеледі; **дайын пікірлер банкі**;
- сабақ редакторы: теория (Markdown, алдын ала көрінісімен), тапсырма құрастырғыш, код тапсырмасының тесттерін дұрыс шешіммен тексеру;
- **тапсырмалар блогы**: сабаққа теориясыз, тек тапсырмалардан тұратын жеке блок қосып (бос немесе сабақ тапсырмаларының көшірмесімен), оны сыныпқа бөлек ашасыз (практика, үй жұмысы). Блокқа мерзім, рубрика және журналдағы баға өз алдына қойылады;
- **AI көмекші** (міндетті емес): оқулық мәтінін қойсаңыз, Gemini теория мен тапсырмаларды жасайды;
- **«Сабаққа дайындық»** (тек мұғалімге): әр сабаққа ҚМЖ (40 минут, .docx экспорт), слайдтар, көрсету режимі (проектор + мұғалім терезесі, таймер), мұғалімнің сөзі, AI көмекші, дайын слайд кітапханасы (6-бөлімді қараңыз);
- **файлдарды автотексеру**: Excel (.xlsx) және Word (.docx) практикалық жұмыстарын сайт өзі ереже бойынша тексеріп (формула, функция, диаграмма, пішімдеу, сүзгі т.б.), рубрика баллын қояды. Оқушы нәтижені бірден көріп, қайта жүктей алады. .xls/.ods немесе оқылмайтын файл мұғалімге жіберіледі. Сайт бағалаған жұмыстарды «Тексеру» бетінің төменгі бөлімінен түзетуге болады. Ашық жауапқа `GEMINI_API_KEY` болса, «AI ұсынысы» батырмасы баға мен пікір ұсынады (мұғалім бекітеді). Ережелер тапсырма `data["auto"]` өрісінде тұрады (`autocheck.py`);
- сыныпты өшіру (оқушылар аккаунты сақталады);
- оқушының құпия сөзін жаңарту.

**Дайын мазмұн (2-тоқсан, 7–11 сыныптар):** теория мен тапсырмалар (қазақша және орысша) және слайд кітапханасы 26 сабаққа дайын. Ең алғашқы 10 сабақ: 7-сынып: «Ақпараттың өлшем бірліктері», «Тармақталған алгоритмдер»; 8-сынып: «Ақпараттарды өлшеу», «While циклі», «For циклі»; 9-сынып: «Бірөлшемді массив»; 10-сынып: «Санау жүйелері», «Логикалық операциялар», «Функциялар мен процедуралар»; 11-сынып: «Жасанды интеллект».

## 0. Ең оңай жол

- **macOS:** `start.command` файлын екі рет басыңыз. Егер «әзірлеуші анықталмаған» деген ескерту шықса, файлдың үстінен оң жақ батырманы басып, **Open (Открыть)** → **Open** таңдаңыз.
- **Windows:** `start.bat` файлын екі рет басыңыз.

Алғашқы іске қосуда кітапханалар өзі орнатылып, демо деректер қосылады, содан кейін браузер ашылады.

## 1. Компьютерде іске қосу (қолмен)

1. Python 3.10 немесе одан жаңа нұсқасын орнатыңыз: https://www.python.org/downloads/ (Windows-та «Add Python to PATH» белгісін қойыңыз).
2. Архивті ашып, папканың ішінде терминал (cmd) ашыңыз.
3. Мына командаларды орындаңыз:

```bash
pip install -r requirements.txt
python seed_demo.py      # демо деректер (міндетті емес)
python app.py
```

4. Браузерде ашыңыз: **http://localhost** (80-ші порт бос болмаса — http://localhost:8080)

**Демо аккаунттар** (`seed_demo.py` іске қосылса):

| Рөл | Логин | Құпия сөз |
|---|---|---|
| Мұғалім | `mugalim` | `mugalim123` |
| Оқушы (8А) | `aruzhan` | `123456` |
| Оқушы (10Ә) | `timur` | `123456` |

Демо аккаунттар тек `seed_demo.py` іске қосылғанда жасалады. Нағыз сайтта оларды жасамаңыз немесе құпия сөздерін өзгертіңіз.

Нағыз мұғалім аккаунтын тіркелу бетінде **мұғалім кодымен** ашасыз. Бірінші іске қосқанда код кездейсоқ жасалады: ол терминалда көрсетіледі және `data/teacher_code` файлында сақталады. Өз кодыңызды `TEACHER_CODE` айнымалысымен беруге болады (төменде қараңыз).

### Сыныпта (бір желіде) пайдалану

Сервер мұғалім компьютерінде іске қосылса, оқушылар сол Wi-Fi/желіден кіре алады:
- мұғалім компьютерінің IP мекенжайын табыңыз (Windows: `ipconfig` → IPv4, мысалы `192.168.1.25`);
- оқушылар браузерге `http://<компьютер-атауы>.local` (мысалы `http://infolab.local`) немесе `http://192.168.1.25` деп жазады. `.local` атауы IP ауысса да өзгермейді: Mac-та «Жүйе баптаулары → Жалпы → Бөлісу → Жергілікті хост атауы» бөлімінде орнатылады.

Платформа интернетсіз де жұмыс істейді: барлық файл жергілікті сақталған. AI көмекшісіне ғана интернет керек.

## 2. Баптаулар (айнымалылар)

| Айнымалы | Мағынасы | Мысал |
|---|---|---|
| `TEACHER_CODE` | Мұғалім болып тіркелу коды | `MeninKodym2026` |
| `SECRET_KEY` | Сессия кілті (интернетке шығарғанда міндетті) | кез келген ұзын кездейсоқ жол |
| `GEMINI_API_KEY` | AI көмекші үшін (тегін: https://aistudio.google.com/apikey) | `AIza...` |

Windows:
```bat
set TEACHER_CODE=MeninKodym2026
set GEMINI_API_KEY=AIza...
python app.py
```
macOS / Linux:
```bash
TEACHER_CODE=MeninKodym2026 GEMINI_API_KEY=AIza... python app.py
```

## 3. Интернетке шығару (барлық оқушы үйден кіруі үшін)

**PythonAnywhere** ұсынылады: тегін тарифі бар және SQLite деректері сақталып қалады.
1. https://www.pythonanywhere.com сайтында тіркеліңіз.
2. **Files** бөліміне архивті жүктеп, ашыңыз (`unzip infolab.zip`).
3. **Web → Add a new web app → Flask** таңдап, `app.py` жолын көрсетіңіз.
4. **Bash** консолінде: `pip install --user markdown`.
5. WSGI файлында `SECRET_KEY` және `TEACHER_CODE` мәндерін `os.environ[...]` арқылы орнатыңыз, содан кейін **Reload** басыңыз.

> ⚠️ Render, Railway сияқты тегін хостингтерде диск әр қайта іске қосылғанда тазаланады, сондықтан бағалар жоғалуы мүмкін. Оларда тұрақты диск (persistent disk) қосу керек.

**Қауіпсіздік туралы:** оқушы кодын сервер бөлек процесте 3 секунд шектеуімен орындайды. Код желіге шыға алмайды, жаңа процесс аша алмайды және өз уақытша папкасынан тыс файлға жаза алмайды. Бұл мектеп деңгейіне жеткілікті қорғаныс. Ал мыңдаған қолданушысы бар ашық сайт үшін кодты бөлек серверде орындаған дұрыс.

## 4. Мазмұн қосу

**Сайттың ішінде:** Мұғалім → **Сабақтар** → сыныпты таңдау → **Өңдеу**.

**Файлмен:** `content/` папкасына `g8-12.json` сияқты файл қосыңыз (код `data/curriculum.json` ішінде). Құрылымы `content/g8-10.json` файлымен бірдей. Содан кейін:
```bash
python load_content.py          # тек бос сабақтарға жүктейді
python load_content.py --force  # бар сабақтарды қайта жазады (оқушы жауаптары өшеді)
```

**Рубрика** (open және file тапсырмаларында) — `data.criteria`: `[{"text": "Шекаралар қойылған", "points": 1}, ...]`. Тапсырма балы осы критерийлер қосындысына тең болады. Критерийлер оқушыға көрінеді.

## 5. Сақтық көшірме

Барлық дерек бір файлда сақталады: `data/platform.db`. Тоқсан сайын оны көшіріп қойыңыз. Жүктелген оқулықтар `data/books/` папкасында, оқушылардың практикалық жұмыс файлдары `data/uploads/` папкасында.

## 5а. Көшіруге қарсы шаралар

- Оқушы тапсырма мәтінін көшіре алмайды, жауап және код өрістеріне мәтін қоя алмайды, экранда атымен су белгісі тұрады.
- Оқушы сабақ бетінен басқа терезеге / ЖИ панеліне ауысса, журналда ⚠ белгісі шығады, оқушы бетінде «N рет шықты, M мин» жазылады.
- Мектеп компьютерлерінде Chrome/Edge ЖИ құралдарын (Google Lens, Gemini, Copilot, ChatGPT т.б.) өшіру: `school-pc/OQY-MENI.txt`.

## 6. Сабаққа дайындық (ҚМЖ, слайд, көрсету)

Мұғалім мәзірінде «Сабаққа дайындық»: сынып → тоқсан → сабақ. Әр сабақта:
- **ҚМЖ редакторы:** үш кезең (басы, ортасы, соңы), әр кезеңде қадамдар (уақыт, педагог/оқушы әрекеті, бағалау, ресурстар, InfoLab тапсырмалары). Қосынды 40 минут болмаса, ескерту шығады. Басқа параллель сыныпқа көшіруге болады. `.docx` экспорт (Times New Roman 12, көлденең бет), сынып тілі орысша болса — КСП орысша. Бір тоқсандағы барлық ҚМЖ — ZIP.
- **Слайдтар:** Markdown, Python кодының түсі (интернетсіз), 16:9. «Дайын слайдтарды жүктеу» батырмасы `content/slides/<код>.json` кітапханасынан сыныптың тіліне қарай слайдтарды ашады. «Теориядан слайд жасау» теорияны `##` бөлімдері бойынша бөледі. PDF — басып шығару беті арқылы.
- **Көрсету:** `.../present` (проектор, толық экран) және `.../present/teacher` (келесі слайд, сөзіңіз, сабақ және кезең таймері, «Тапсырмаларды сыныпқа ашу»). Пернелер: ← → бос орын, F, B. Күй сервер арқылы 1 секундта жаңарады, сондықтан телефонмен де басқаруға болады.
- **AI (міндетті емес):** «Жоспар жасау (AI)» толық ҚМЖ + слайд + сөзді жасайды (оқулық PDF-ін көз ретінде алады), слайд редакторында «Толығырақ / Мысал қос / Қарапайым түсіндір / Қысқарт» батырмалары бар. `GEMINI_API_KEY` керек.

Бөлім тек мұғалімге ашық, оқушы беттері өзгермейді. Кодта: `planner.py`, `planner_docx.py`, `planner_slides.py`, `planner_ai.py`, `templates/planner/`, `static/planner.*`, `static/slides*.{css,js}`, `static/present.*`.

**Слайд кітапханасын толықтыру:** `content/slides/g8-06.json` үлгісімен жаңа файл қосыңыз: `{"code": "g8-10", "kk": [{"phase": "start|middle|end", "md": "...", "notes": "..."}], "ru": [...]}`.

**Теорияны оқулықтан қайта жасау (Gemini):** `GEMINI_API_KEY=... python regenerate_theory.py 8 2` (8-сынып, 2-тоқсан; тек қысқа теориялар; тапсырмаларға тиіспейді).
